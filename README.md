# 🇮🇪 Dublin Hustle

**Dublin Hustle** is a browser-based, GTA-style mini game set in Ireland.

Play as a lad in Dublin trying to survive the streets while avoiding the Garda and completing dodgy missions like delivering spice bags across town.

Built to run on:
- 💻 Computer
- 📱 Phone
- 📲 Installable as an app (PWA)
- 🌍 Works in any modern browser

---

## 🎮 Gameplay

- Move around the map using WASD (keyboard) or touch buttons (phone)
- Avoid the Garda who chase you
- Explore the map
- Complete missions (more coming soon)

This project is inspired by classic top-down GTA games with Irish humour and local references.
